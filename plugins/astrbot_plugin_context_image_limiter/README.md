# 上下文图片大小限制


## 设置

在 AstrBot 网页端：插件 → 上下文图片大小限制 → 配置齿轮。

`上下文图片总大小上限 (MB)` 默认 **10**，支持大于零的小数，例如 5、10、20、0.5。无效值按 10 MB 处理。

## 行为

- 每次模型请求前检查全部图片，包括历史、当前消息和工具调用新增的图片。
- 总大小超限时，从最旧图片开始移除，直到不超过上限。单张新图片过大时也可能被移除。
- 移除的是上下文中的图片数据，并添加短文字提示；不删除原图片文件，不删除聊天轮数、文字或工具调用记录。
- 正常完成的一轮会把清理后的上下文保存到会话；安装不会批量修改数据库中的历史会话。
- 按实际传输的 Base64 图片字符串统计，包含编码开销；1 MB = 1,000,000 字节。尚未转为内嵌数据的远程图片 URL 只计算 URL 本身，不下载测量。
- 配置对后续请求生效，不取消已经发出的请求。

## 实现与兼容性

注册请求、Agent 开始和完成事件，并在运行时包装 `ContextManager.process`，覆盖工具循环中的每一次模型请求。调用 AstrBot 原有的压缩流程，不修改核心文件。停用时恢复包装，或在后续其他插件包装存在时将自身包装置为不生效。

没有额外第三方依赖。升级 AstrBot 后应检查 `ContextManager.process` 接口及插件事件是否兼容。

测试：纯逻辑 11 项，AstrBot 容器集成 4 项。集成测试需要在 AstrBot Python 环境中运行。
