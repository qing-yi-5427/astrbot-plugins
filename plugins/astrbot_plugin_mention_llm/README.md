# QQ 群 @ 唤醒 LLM

保留原有 `/aa` 唤醒配置与对话逻辑，让 QQ 群里的 `@机器人 你好` 也能进入同一个 LLM 对话流程。适用于 AstrBot 的 `aiocqhttp` / OneBot 11 平台及本地 Agent，已在 AstrBot v4.28.2 上验证。

## 使用

- `@机器人 你好`：正常对话，不必再输入 `/aa`。
- `@机器人 帮我画一张猫图`：进入原有人格与工具流程；是否能画图取决于已配置的模型和生图工具。
- `@机器人` 后附图片、语音或引用消息：保留 AstrBot 原有的附件与引用处理。
- 只发送 `@机器人`、不含其他内容：沿用 AstrBot 自带的“空 @ 等待”和“空 @ 需要回复”设置；该内置功能没有被替换。
- `/aa 你好`、`/i`、其他原有命令及普通群消息：维持原有行为。插件不主动回复普通消息，不响应 @其他人、@全体成员、引用里包含的 @ 或纯文本假 @。

## 安装

将本插件目录复制到 AstrBot 的 `data/plugins/astrbot_plugin_mention_llm/` 后重载，或在插件管理页面上传本插件独立 ZIP。无需修改全局唤醒前缀、LLM 额外唤醒前缀、模型、人设或其他插件配置，无额外依赖。

这是多插件仓库中的独立目录，不要把集合仓库地址直接用于单插件 Git 安装。停用或卸载本插件即恢复原有行为。

## 实现与边界

插件在 `on_waiting_llm_request` 中标记**当前消息顶层明确 @ 当前机器人**的 QQ 群事件。该钩子由 AstrBot 调度，遵守配置文件的插件选择、会话插件禁用设置，以及 AI 启用和会话权限检查。已经准备好的插件请求不会被覆盖。

为不修改消息文本或已有 `/aa` 链路，插件对本地主 Agent 的 `collect_initial_request` 引用安装可撤销的运行时包装：仅在当前 @ 请求原本会被额外前缀拦截时，复制本次调用的构建参数，将副本的额外前缀置空。其他调用以原始参数原样转交；不改全局配置、不修改 AstrBot 核心文件、不修改共享 Provider 或人格。

请求仍在 AstrBot 原有会话锁内采集，由原流程读取对话与附件，然后构建人格、记忆、工具、模型回退和最终回复。插件不自行调用模型，不创建第二个 Agent，不增加模型轮数，不重复写聊天历史，也不修改其他插件的表情回应触发规则。

此实现依赖 AstrBot 本地主 Agent 的内部采集接口。插件加载时检查接口签名，不兼容时明确报错而不安装包装；停用时撤销自身包装。若其他插件在其后又包装了同一引用，停用后自身包装仅透传，不覆盖其他插件。

不支持第三方远程 Agent、私聊或 QQ 以外的平台。全局 AI 被关闭、会话禁用 AI、消息被权限/白名单/其他命令拦截时，不强行调用 LLM。只 @ 的内置等待逻辑仍可能在 60 秒内接收该用户的下一条消息，这是原有功能。

## 验证

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

`tests/native_smoke.py` 可在有真实 AstrBot v4.28.2 环境的独立进程运行，验证请求采集、图片/引用/语音、并发隔离、`/aa` 原样透传及停用恢复。所有模型、平台和会话存储调用均使用离线替身，不消耗模型额度、不发送 QQ 消息。
