# 图片与主题

合并生图/GIF、工具调用保障与发送确认、图片来源搜索、文转图主题/Git 同步、真实模型页脚和群分析主题联动。只有本插件一个注册入口；三组功能保留独立开关。

**设置：AstrBot → 插件 → 图片与主题 → 配置齿轮。** 三组原生可视化表单涵盖生图连接/模型/格式/预算、主题/头像/Git、搜图引擎/缓存/网络等原设置。

保留 `/i`、`/imagegen`、`/生图`、`/i --gif`、`/t2i`、`/图样式`、搜图关键词和管理指令；模型工具仍叫 `astrbot_generate_image`。普通聊天不注入生图提示或调用生图服务，明确请求仍由对话模型组织 prompt 后通过原生工具执行。

文转图服务继续独立部署；原生主题协议 1，Git 主题需 T2I 2.1.0+，主题群分析需支持 `report_style_protocol: 1` 的 2.3.0-themed-reports。六主题、昵称标签和会话主题选择不变。旧独立 model_footer 不再需要。

兼容 AstrBot 4.29.4，元数据暂限 4.29 系列。升级请先阅读 [设置与迁移说明](../../docs/QING_SUITES_SETTINGS.md)，停用旧功能插件后再安装；继续使用旧主题与搜图专属数据目录，避免状态丢失。配置和密钥不进入 Git。

搜图模块保留原 MIT 许可及作者信息；源代码与许可见 `features/image_source/`。不包含第三方群分析插件本体。
